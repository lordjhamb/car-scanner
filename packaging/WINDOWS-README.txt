Car Scanner for Windows
=======================

1. Double-click CarScanner.exe. A black window opens; that window IS the app's engine.
   Your browser opens Car Scanner at http://127.0.0.1:8077
2. To stop Car Scanner, use "Quit Car Scanner" in the app, or close the black window.

First launch: if Windows SmartScreen says it "protected your PC", click More info -> Run anyway.
(The app isn't signed with a paid code-signing certificate yet.)

vLinker FS adapter: if it doesn't appear in the list of adapters, install the FTDI VCP driver:
https://ftdichip.com/drivers/vcp-drivers/

Your data (garage, scans, photos) is stored in %APPDATA%\Car Scanner
Project home: https://github.com/lordjhamb/car-scanner
